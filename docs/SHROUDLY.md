# Shroudly DPI Evasion Engine Integration

هذا الدليل يوضح دمج محرك [Shroudly](https://github.com/umutxyp/Shroudly) (رخصة MIT) كميزة إضافية في تطبيق سيرفراتي (v2rayNG) لتخطي حجب المواقع وفحص الحزم العميق (DPI Evasion).

---

## 1. ما هو Shroudly وكيف يعمل؟

Shroudly هو محرك C خفيف ومصمم لتخطي أنظمة فحص الحزم العميق (DPI) التي تحجب المواقع أو تشوّش على الاتصالات المشفّرة (TLS/HTTPS).
يقوم المحرك بتفتيت حزم الـ TLS Client Hello وإعادة ترتيبها أو إرسال بايتات تمويهية (OOB / Out-of-band) بحيث تعجز أجهزة الـ DPI عن قراءة الـ SNI (اسم الموقع المطلوب)، بينما يجمع خادم الوجهة الحزم بشكل طبيعي تماماً.

---

## 2. أوضاع التشغيل (Operating Modes)

يدعم التطبيق وضعين رئيسيين:

### الوضع الأول: Mode A — «🛡️ فك الحجب بدون سيرفر» (Standalone Mode)
- **المسار:** `التطبيقات` ➔ `VpnService` ➔ `hev-socks5-tunnel` (مع `mapdns`) ➔ `محرك Shroudly` (SOCKS5 127.0.0.1) ➔ `الإنترنت مباشرة`.
- **المميزات:**
  - يعمل بدون الحاجة لاختيار أو امتلاك أي سيرفر خارجي.
  - خفيف وسريع جداً على البطارية وموارد الجهاز.
  - حل مثالي لتصفح المواقع المحجوبة محلياً في مصر، عُمان، إيران، وروسيا.
- **تنبيه:** هذا الوضع **لا يغير الدولة ولا يخفي الـ IP الحقيقي**، بل يفك حجب المواقع فقط.

### الوضع الثاني: Mode B — «تمويه الاتصال بالسيرفر» (Server Camouflage / Chain Mode)
- **المسار:** `التطبيقات` ➔ `xray-core` ➔ توجيه الـ Outbound عبر `streamSettings.sockopt.dialerProxy = "shroudly-out"` ➔ `محرك Shroudly` (SOCKS5 127.0.0.1) ➔ `خادم الـ VPS (VLESS/VMess/Trojan)`.
- **المميزات:**
  - تمويه وحماية الاتصال بالسيرفر نفسه ضد الحظر والتفتيش.
  - يخفي عنوان الـ IP الحقيقي كالمعتاد (عبر السيرفر).
- **التوافق:**
  - يتوافق مع جميع بروتوكولات TCP (مثل VLESS, VMess, Trojan, Shadowsocks).
  - يتجاوز بروتوكولات UDP المباشرة (WireGuard و Hysteria2) للحفاظ على استقرارها.
  - يتعامل بذكاء مع الـ Fragment الداخلي لـ Xray لتجنب التفتيت المزدوج.
  - اختبارات البينج الحقيقية (Real Ping) تفحص السيرفر مباشرة لقياس دقيق لزمن الاستجابة.

---

## 3. استراتيجيات التمويه (Evasion Strategies)

- **`auto` (موصى به):** يجرب استراتيجية `tlsrec(sni+1)` مع الاستكشاف التلقائي لردود الخوادم.
- **`split(sni)`:** يقسم حزمة الـ Client Hello عند بداية حقل الـ SNI.
- **`tlsrec(sni+1)`:** يضع أول بايت من الـ SNI في سجل TLS منفصل.
- **`disorder(sni)`:** يرسل بايتات الـ SNI بترتيب غير متزامن.
- **`oob(sni+1)`:** يرسل بايت خارج النطاق (Out-Of-Band) قبل الـ SNI لإرباك جدار الـ DPI.
- **`split(1),tlsrec(sni+1)`:** دمج تفتيت الحزمة الأولى مع تقسيم سجل الـ TLS.

---

## 4. خيار تعطيل QUIC (Drop UDP 443)

بروتوكول QUIC (HTTP/3) يعمل عبر UDP ولا يخضع لتقنيات تمويه الـ TCP TLS. عند تفعيل خيار "تعطيل QUIC"، يُسقط المحرك اتصالات UDP 443، مما يجبر المتصفحات على التراجع إلى TCP، لتطبيق تقنيات التمويه بنجاح 100%.

## 5. البناء والتحديث البرمجي

### بناء مكتبة المحرك (Native Libraries):
```bash
./compile-shroudly.sh
```
يقوم السكريبت بتجميع `libshroudlycore_jni.so` لجميع المعماريات الأربع:
- `arm64-v8a`
- `armeabi-v7a`
- `x86_64`
- `x86`

### تحديث قائمة الـ Block IPs:
```bash
node scripts/gen-shroudly-block-ips.js
node scripts/gen-shroudly-block-ips.js --check
```
يستخرج الآيبيات والمخادع الرقابية المحظورة من بصمات الرقابة إلى `V2rayNG/app/src/main/assets/shroudly/block-ips.txt`.
